# Accuracy

Does every scheme have the order it declares, in every way SELAH can run it? And where is it stable?

| Case | Type | What it verifies |
|---|---|---|
| [A1 Order conditions](./order-conditions) | physics | the coefficients satisfy the order conditions of their declared order, and fail one of the next |
| [A2 Orders on scalar ODEs](./scalar-orders) | physics | the observed order on a linear and a nonlinear ODE |
| [A3 Orders through the stepper](./stepper-orders) | physics | the observed order of every scheme in every storage form, driven by the stepper |
| [A4 Splittings](./splittings) | physics | the observed order of the four compositions, both partition orders, two Hamiltonian problems |
| [A5 Linear stability](./stability) | physics | the stability regions from the library's own tableaux, against closed forms and the SSP disc |
